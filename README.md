# Portfolio

Welcome to my portfolio repository.

This portfolio is built with React and Vite and showcases a selection of projects from my Multimedia Design education. It reflects my interest in UX/UI design, frontend development and creating user-centred digital experiences.

## Live portfolio

https://eaa25cmc.github.io/

## About

The portfolio was developed using React and Vite, with a portfolio template as the starting point. I have customised the design, structure and content to create a portfolio that reflects my own visual identity and showcases my work.

The website includes:

- Home page
- Projects overview
- Individual project pages
- About page
- Contact page
- Responsive design
- Custom 404 page

## Featured projects

### Rumly

A roommate-matching application that helps users find compatible roommates through a personalised quiz and matching experience.

### Little Looms

A retail concept for children's fashion focusing on branding, UX/UI design and responsive interfaces.

### Lumina Audio

A product landing page designed to present and promote the Lumina One speaker through visual storytelling and interaction design.

## Running the project

- Install dependencies with `npm install`
- Start the development server with `npm run dev`
- Create a production build with `npm run build`
- Preview the production build with `npm run preview`

The development server normally runs at:

`http://localhost:5173`

## Deployment

The portfolio is deployed on GitHub Pages. Every push to the `main` branch automatically triggers a new deployment through GitHub Actions.
